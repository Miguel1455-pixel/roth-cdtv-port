Olá! Meu nome é **Miguel**, tenho 12 anos e este é o meu primeiríssimo port de jogo para um console! Adaptei o clássico fan-game *Return of the Hylian* para rodar direto no hardware do **Amiga CDTV**. 

Estou estudando para ser programador de jogos e conto com o apoio dos meus responsáveis, Luana e Marcello, nesta jornada!

---

## 📥 Como Baixar o Jogo

A imagem de CD prontinha para jogar (.ISO) está disponível para download seguro na área de **main** deste projeto!

👉 Para baixar, olhe no menu do lado direito da tela, clique em **main** e baixe o arquivo `roth_cdtv_v1.iso`.

---

## 💿 Como Jogar / Gravar

* **No Hardware Real (Amiga CDTV):** 
  1. Baixe o arquivo `.iso`.
  2. Grave a ISO em um CD-R de boa qualidade.
  3. Use a menor velocidade possível que o seu gravador permitir (ex: 2x ou 4x) para que o leitor antigo do CDTV consiga ler perfeitamente.
  4. O jogo dá boot automático no console!

* **No Emulador (WinUAE):** 
  1. Configure o WinUAE no perfil padrão do Amiga CDTV.
  2. Ative a ROM estendida do CDTV (CDTV Extended ROM).
  3. Nas opções de CD, aponte o drive virtual direto para o arquivo `.iso`.
